# 多语言（i18n）

界面文案支持 OpenMinis 同款的 18 种语言：简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português (Brasil)、Русский、ไทย、Bahasa Indonesia、Bahasa Melayu、Türkçe、Polski、Română、Hrvatski、Filipino。

## 设计

源码里的中文原文就是翻译键。界面代码写 `t('保存')`，运行时按当前语言查表：

1. 当前语言的词条；
2. 否则英文词条；
3. 否则原样返回中文。

因此新增文案不需要先改资源文件；缺失翻译也永远不会出现空白标签。简体中文是默认语言，此时 `t()` 直接返回原文，零开销。

- `core/I18n.ets`：语言列表、语言标签归一化（`zh-CN`→`zh-Hans`、`zh-TW/HK/MO`→`zh-Hant`、`pt-*`→`pt-BR`、`tl`→`fil`、`in`→`id`）、词条注册与查询、`i18nVariants()`。
- `service/I18n.ets`：启动时读取已保存语言（没有则取系统的 `i18n.getSystemLanguage()`），从 rawfile 同步加载英文与目标语言；切换语言时加载并持久化到 `preferences`（`minis_i18n_v1`），同时写 `AppStorage` 的 `i18nVersion`。
- `entryability/EntryAbility.ets`：`onCreate` 里最先初始化；`entryformability/EntryFormAbility.ets` 在 `onAddForm` 里初始化，保证服务卡片也走同一套文案。
- 界面组件用 `@StorageProp('i18nVersion')` 订阅变化；切换语言后当前页面立即重建，无需重启。

词条文件位于 `entry/src/main/resources/rawfile/i18n/<language>.json`，是扁平的 `{ "中文原文": "译文" }` 对象。`zh-Hant.json` 单独命名，其余使用语言代码。文件随 HAP 打包，启动时用 `resourceManager.getRawFileContentSync` 同步读取，避免首帧闪烁。

## 语言选择

设置页「语言」区域列出 18 种语言的自称。点击后：

- 加载英文（兜底）与目标语言词条；
- 立即切换到新语言并触发界面重建；
- 保存到 preferences，下次启动沿用；
- 提示「语言已切换」。

已保存的会话、消息和导出文件不会改写，始终保留生成时的原文。

## 固化文案的处理

不是所有中文字符串都应该进入词条表：

- **持久化内容的识别标记**（子代理后台消息前缀、摘要前缀、导入标题后缀等）保持中文常量不变，否则切换语言后无法识别旧数据。需要识别的地方用 `i18nVariants('前缀')` 同时匹配所有已加载语言的写法（`MessageBubble.isSummary()`）。
- **协议/逻辑字符**（Markdown 标点判断、LaTeX 符号、文件扩展名）不做翻译。
- **日期等数字顺序随语言变化的格式**不做片段拼接。`service/Format.ets` 的 `shortMonthDay()` 按当前语言选择「M月D日」「M/D」「D.M.」等顺序，避免把「月」「日」当成独立词翻译后拼出“11Buwan8Araw”。
- **模块级常量**不能直接 `t()`：ES 模块在 `EntryAbility.onCreate` 之前求值，那时词条尚未加载。凡是顶层就调用 `t()` 的常量都改为函数（`interruptedResult()`、`summaryInstruction()`、`soulPresets()`、`builtinDescription()` 等），或在数据里保留中文、渲染时再 `t()`（思考档位、工具标签、模型备注、主题色名称、输入建议）。
- 空字符串翻译是合法值（例如英文里日期后缀「日」译为空），`t()` 必须尊重显式空值而不是回退。

## 翻译流水线

1. 从源码提取被 `t()` 包裹的中文字面量，生成 `scripts/i18n-source.json`（当前 1221 条）。
2. 按约 306 条切块，每块一个 JSON 数组。
3. 每种语言由独立翻译任务产出 `{ 中文: 译文 }`，要求键集合与源数组完全一致，占位符、URL、路径、模型 ID、工具名、技术术语保持原样。
4. `node scripts/i18n-merge.mjs <chunks-dir>` 校验键、拒绝非字符串、统计缺失；缺失超过 2% 时拒绝写盘。通过后输出到 `rawfile/i18n/<language>.json`。
5. `scripts/test-core.mjs` 覆盖语言归一化、18 种语言列表、直接命中/英文兜底/原文兜底、显式空翻译、`i18nVariants()` 的跨语言匹配。

新增语言时需要：在 `I18N_LANGUAGES` 里加一项；准备词条文件；在 `normalizeI18nLanguage` 里补特殊标签（如果系统语言标签不标准）。不需要改任何界面代码。
